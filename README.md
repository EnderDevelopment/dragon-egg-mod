# Dragon Egg Mod

Adds a unique Dragon Egg item with phase abilities to Minecraft Fabric.

## Features

- Adds a unique Dragon Egg item with an enchantment glint
- Allows players to cycle through different phases with unique effects

## Requirements

- Minecraft 1.21.11
- Fabric Loader 0.14.0 or higher
- Fabric API 0.91.0 or higher

## Installation

1. Download the mod JAR file from the releases page.
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Craft or obtain the Dragon Egg item.
2. Right-click the Dragon Egg to cycle through different phases.
3. Each phase has unique effects that change your abilities and appearance.

## Configuration

The mod does not have any configuration files. All settings are hardcoded within the mod.
